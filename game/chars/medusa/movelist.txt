Medusa - move list
========================================

Default keys: A light punch | S heavy punch | Z light kick | X heavy kick
             D special button | C super button | Enter taunt
Throw: Forward or Back + S (close) | Run: Forward,Forward | Hop back: Back,Back | Air recovery: A+S

Move                                   Easy input (classic input)     
----------------------------------------------------------------------------------------------------
Venomous Flame                         D (QCF + P)                    Three-hit poisonous flame
Serpent Lunge                          Forward + D (QCB + P)          Fast lunging strike
Spatial Seal                           Down + D (D, D + P)            Seals space and freezes the foe in place
Seven-Coloured Sky Swallowing Python   C (1 bar) (QCF, QCF + P)       Rainbow python charges across the screen
Spatial Collapse                       Down + C (2 bars) (QCB, QCB + P) Crushing vortex around the foe
